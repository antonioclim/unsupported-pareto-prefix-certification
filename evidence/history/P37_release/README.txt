Start here

Extract the archive into a new directory and open a terminal in the directory
containing this README. RESULTS_MAP.md links the named manuscript results to
proof locations, exact inputs, checks, outputs and the scope of each check.
The current manuscript and Supplementary Materials are separate submission
documents. The historical P21 manuscript is retained as a checker input and is
excluded from the new CC BY grant.

Core checks use only the Python standard library. The recorded environment is
Python 3.12.14 on Linux. Use Python 3.12 or later without -O: mathematical checks
use assertions. The declared route is Linux or Windows Subsystem for Linux;
other platforms have not been tested here. No installation, network call,
hardware access or LaTeX compilation is needed for these commands.

1. Verify the packaged bytes (no scientific programs are executed):

   python3 run_checks.py --verify-only --record results/Integrity_Local.json

2. Execute the seven current checker entries:

   python3 run_checks.py --record results/Current_Local.json

   Expected: six scientific checks and one control, all PASS. The control
   rejects four deliberately malformed algebraic certificates.

3. Execute current and selected historical checks together:

   python3 run_checks.py --legacy --record results/Full_Local.json

   Expected: seven current entries PASS, plus 26 historical scientific
   programs and 27 historical outputs byte-identical. The wireless producer
   is one of those 26 programs and produces two of those 27 outputs; it is
   not counted twice. The complete route therefore runs 32 scientific
   program entries and one malformed-certificate control. Some checks use
   different methods on the same result; this is not 32 independent findings.

4. After the command finishes, inspect its new report:

   python3 -c "import json; r=json.load(open('results/Full_Local.json')); print(r['status'], r['run_id'], r['finished_at_utc'])"

   Use Current_Local.json or Integrity_Local.json for the other commands.
   Completion requires exit code 0 and status PASS for this invocation.
   Each report has a fresh run_id, start time and finish time. RUNNING is an
   incomplete attempt. Exit 1 means execution/comparison failure; exit 2
   means preflight or command-line failure. Do not infer success from a
   previously saved PASS file. Safe valid report destinations receive a
   fresh FAIL on a frozen-input preflight failure. Invalid arguments or an
   unsafe/unwritable destination may prevent a new report; the command then
   reports that failure on the console and must not be treated as successful.

Reports are replaced atomically, after first recording RUNNING. Inside the
package they must be under results/. Existing unrelated external files,
source files and symbolic-link destinations cannot be overwritten. Relative
--record paths are relative to the terminal's current directory. New local
reports and Python caches are excluded from the frozen manifest.

On a failure, read the error and captured stdout/stderr in the JSON report.
Restore a fresh extraction if frozen bytes differ. Do not edit the expected
outputs or manifest to suppress a failure. freeze_inputs.py is a maintainer
snapshot utility, not a reproduction or recovery command.

What is compared

All work takes place in temporary copies. Each current output is removed
before its producer executes. Six current outputs require exact bytes. The
candidate-observation check compares exact JSON after excluding only its two
declared runtime fields, elapsed_seconds and python_version. A zero process
exit code is insufficient: required outputs and their scientific content must
also agree, and any output status must be PASS.

run_legacy_checks.py is the current orchestration of the unchanged historical
programs. Its wireless JSON and CSV outputs are both removed before production
and both must be regenerated byte-identically. The three earlier replayers
already use source-only inner workspaces. The original historical orchestration
and all its input bindings remain unchanged under legacy/; use the current
root command above for the corrected reproduction route.

Scientific figures in figures/ have a separate regeneration
route and optional plotting dependencies described there. Plotting is not a
dependency of the standard-library scientific checks or their PASS status.

Scope

The polynomial checks verify 48 boxes and 4,644 rational coefficients under
the analytic reduction in the uniform triangle policy proof. The second check
uses a separate coefficient-recovery method; it is not an external review or
a proof assistant. Finite ordinal, reduction, candidate and transfer checks
corroborate only their declared cases. Universal proofs are in the manuscript
and Supplementary Materials and are not executed by this package.

The APEX replay analyses existing trial summaries: 1,536 overlapping tasks,
41 positive tasks all requiring nine observations, and 1,495 negative tasks.
It supplies no new physical measurements, independent replications, observed
disclosure saving or validation of a 6G/7G or WPT system.
