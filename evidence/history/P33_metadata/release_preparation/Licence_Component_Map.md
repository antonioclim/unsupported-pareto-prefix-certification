# Component rights and proposed release scope

Local preparation dated 24 October 2026. This document does not grant a new licence or authorise publication.

| Component | Current evidence | Proposed treatment |
|---|---|---|
| APEX dataset originals, README and secondary extracts | Upstream CC BY 4.0; DOI 10.3217/3dhx0-2k125; retained attribution and legal code | Preserve the original files and notices, link the licence and identify the transformations. No additional restriction applies to the upstream material. |
| New verification and figure-generation code | Author's release decision remains unconfirmed | Propose BSD-3-Clause for material the author is entitled to license; retain any existing component notices. |
| New explanatory documentation, exact-result tables and generated figures | Author's release decision remains unconfirmed | Propose CC BY 4.0 for material the author is entitled to license. |
| Manuscript and Supplementary Materials | Prepared for author review and intended journal submission | Keep outside the initial public companion unless the author explicitly includes them and selects compatible terms. |
| Historical code, evidence and embedded Research_Companion_Paid_Prefix_v1.zip | Retained bytes and provenance; the embedded notice explicitly leaves the author's new-material licence undecided | The embedded inventory has been inspected statically and recorded in `Embedded_Rights_Inventory_P33.json`. Apply any later author-approved grant to its intended scope without altering upstream notices. |
| SIAM document class | Privately obtained unchanged, with a complete-package redistribution condition | Excluded from delivered archives. PDF build instructions identify the dependency and hash; obtain the official complete macro package separately. |
| Cover letter, author confirmations, private audit records | Submission preparation and internal review | Exclude from public release. |

The proposed public payload is the reproducibility companion, its active figure generators, results map, citation file and release documentation. The author-review master is not a public-release payload. The new code and documents have not silently been placed under the proposed licences; upstream permissions remain unaffected.

Public metadata must be completed only after the author approves the actual payload, rights and release. A GitHub URL, Zenodo version DOI, concept DOI and release date are deliberately absent when no such release exists. The eventual DOI must identify the newly published version, not an older OPTL/CDRSE record.

Primary licence sources checked on 24 October 2026:

- BSD-3-Clause: https://opensource.org/license/bsd-3-clause
- CC BY 4.0: https://creativecommons.org/licenses/by/4.0/ and the retained upstream legal code.
- APEX attribution: `reproduction/legacy/p9/licence/THIRD_PARTY_APEX.txt`.

This map records provenance and the proposed distribution choices. It does not infer that a licence for data also licences the associated paper, software or every file in a mixed archive.
