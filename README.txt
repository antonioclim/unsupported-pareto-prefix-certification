# The Price of Finding a Certificate: Unsupported Pareto Points under Prefix Queries

Reproducibility companion v1.2.0 by Antonio Clim.
Version DOI: <https://doi.org/10.5281/zenodo.23936602>.

Start with the [documentation and research notes](docs/README.md) or the
[offline reading view](docs/README.html). The companion provides exact
certificates, scientific software and retained computational evidence.
The software follows the v1.1.0 baseline archived at
<https://doi.org/10.5281/zenodo.23646970>.

Run these commands from the repository root:

```bash
python3 run_all_checks.py --verify-only
python3 extensions/P58/run_research_P58.py --mode core
```

The identity check validates frozen inputs. The research command runs the
retained core check suite under its documented dependencies. Study the
[research notes](docs/INTEGRATION_INDEX.md) for the scope of each result,
the limits of dimensional transfer and the assumptions of the archived replays.

The public companion contains software, evidence and selected notes. The
complete article and Essential Supplement are held with the submission files.
See the [component rights](RIGHTS_NOTICE.md) and the
[frozen scientific licensing terms](LICENSING.md).

The [GitHub release](https://github.com/antonioclim/unsupported-pareto-prefix-certification/releases/tag/v1.2.0) and
[Zenodo record](https://zenodo.org/records/23936602) are the distribution points for
`unsupported-pareto-prefix-certification-v1.2.0.zip`. GitHub's generated source archives follow the repository layout.
